# SQL

This folder contains the complete MySQL analysis script for the Superstore project.

## File

`superstore_sales_analysis.sql`

The script demonstrates:

- data validation
- aggregate functions
- customer and product analysis
- regional sales analysis
- `CASE` expressions
- common table expressions (CTEs)
- window functions
- ranking functions
- year-over-year growth analysis
- running totals
- reusable SQL views
