# Data

This folder contains the Superstore sales dataset used in the SQL analysis.

## File

`superstore_sales.csv`

The dataset contains U.S. retail transaction records covering customer, product, geographic, shipping, and sales information.

Key fields used in the analysis include:

- `Order_ID`
- `Order_Date`
- `Ship_Date`
- `Ship_Mode`
- `Customer_ID`
- `Customer_Name`
- `Segment`
- `City`
- `State`
- `Region`
- `Product_ID`
- `Category`
- `Sub_Category`
- `Product_Name`
- `Sales`
